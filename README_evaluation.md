# RAG答案准确性评估系统

## 概述
本系统使用大模型（DeepSeek）来评估RAG系统生成的答案是否准确，通过对比标准答案和RAG生成的答案，给出准确性判断。

## 文件说明

### 1. 核心文件
- `answer_evaluator.py` - 完整的评估器类，包含所有功能
- `full_answer_evaluator.py` - 批量处理所有数据的完整评估脚本
- `sample_evaluator.py` - 处理少量样本数据的快速测试脚本
- `quick_test_evaluator.py` - 快速测试脚本

### 2. 输入文件
- `batch_20_results.csv` - RAG系统生成的结果文件
- `D:\BaiduNetdiskDownload\code\1022_90%\insurance_qa_pairs_20251022_233322.csv` - 标准答案文件

### 3. 输出文件
- `sample_evaluation_results.csv` - 样本评估结果（10条记录）
- `final_answer_evaluation_results.csv` - 完整评估结果
- `batch_X_Y_evaluation_results.csv` - 分批处理的结果文件

## 使用方法

### 快速测试（推荐先运行）
```bash
python sample_evaluator.py
```
这将处理前10条记录，快速验证系统是否正常工作。

### 完整评估
```bash
python full_answer_evaluator.py
```
这将处理所有数据，分批进行评估，避免API限制。

## 输出格式

评估结果包含以下5列：
1. **产品** - 保险产品名称
2. **问题** - 用户提出的问题
3. **正确答案** - 标准答案
4. **RAG答案** - RAG系统生成的答案
5. **是否准确** - 评估结果（准确/不准确/部分准确/无法评估/评估失败）

## 评估标准

系统从以下三个维度评估答案质量：
1. **信息准确性** - RAG答案中的关键信息是否与正确答案一致
2. **完整性** - RAG答案是否包含了正确答案的主要要点
3. **相关性** - RAG答案是否直接回答了问题

## 评估结果分类

- **准确** - 在信息准确性、完整性和相关性方面都表现良好
- **不准确** - 存在明显错误、遗漏重要信息或偏离问题
- **部分准确** - 部分正确但存在一些问题
- **无法评估** - 未找到对应的标准答案
- **评估失败** - 评估过程中出现技术错误

## 统计信息

系统会自动生成以下统计信息：
- 总体准确性分布
- 按产品分类的准确性统计
- 总体准确率（准确+部分准确的比例）

## 注意事项

1. **API限制** - 系统在每次API调用后添加延迟，避免触发API限制
2. **分批处理** - 大量数据会分批处理，每批生成单独的结果文件
3. **错误处理** - 包含完善的异常处理机制，确保评估过程稳定
4. **备份机制** - 分批结果会单独保存，避免数据丢失

## 示例结果
